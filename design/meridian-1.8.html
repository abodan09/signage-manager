Settings

Connection details and setup instructions.

Local server

Serves this console and the TV player to every screen on your network. All TVs must be on the same network as this PC — VPN and virtual adapters are ignored automatically.

http://192.168.1.24:3001

Server URL for TVs — enter this on the TV setup screen. The console itself runs at http://localhost:3001, which a TV can never reach.

Android TV setup

Install the APK, then point the screen at this server. Configuring the URL over ADB skips the on-screen setup entirely.

  1. Enable developer options on the TV: Settings → About → Build (click 7×), then turn on USB debugging.
  2. Find the TV's IP under Settings → Network → Status, then adb connect <TV-IP>.
  3. Install the player: adb install app-debug.apk.
adb shell am start -n com.signage.tvplayer/.SetupActivity --es SERVER_URL "http://192.168.1.24:3001"

Anonymous usage statistics

Reports which features are used and that the app is running. Only a random install ID, app version, OS and named feature events are sent — never your content, media, file names, or any personal data.

Scaling to a fleet

Install the same APK on every TV and point them all at this server URL. Each TV auto-registers with a unique device ID. Use Devices to name and group each screen, Screen Layouts to frame what they show, and Emergency to take them all over at once.

For remote deployments — TVs not on this LAN — run the server on a cloud VPS and update each TV app's server URL to the public address.
