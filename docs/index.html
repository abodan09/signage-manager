Install guides

Getting a player onto the TV.

Each platform wants a slightly different dance. Pick yours — every one of them ends the same way, with the server URL from the desktop app's Settings page.

STEP 01

Enable Developer Mode on the TV

Settings → Device Preferences → About → scroll to Build and click it 7 times, until "Developer mode enabled" appears.

STEP 02

Turn on USB / network debugging

Settings → Device Preferences → Developer Options → enable USB debugging, and note the TV's IP address under Settings → Network.

STEP 03

Connect over ADB

From the Windows PC running the desktop app, open a terminal:

adb connect <TV-IP>
STEP 04

Install the APK

Point ADB at the file you downloaded:

adb install signage-tv-player.apk
STEP 05

Set the server URL

The app opens a setup screen. Enter the server URL shown on the desktop app's Settings page — or skip the screen entirely with the ADB command below.

STEP 06

Done — it auto-starts on boot

The player launches when the TV powers on. Hold OK for 3 seconds to get back to the setup screen.

Skip the setup screen from the PC

Replace 192.168.1.x with the IP shown on the desktop app's Settings page, then run this once after installing:

adb shell am start -n com.signage.tvplayer/.SetupActivity --es SERVER_URL "http://192.168.1.x:3001"

Updating from v1.5.2 or earlier?

Releases from v1.5.3 are signed with a permanent release key — older builds used a throw-away debug key — so the first update needs a clean install. Run adb uninstall com.signage.tvplayer before installing the new APK. Later updates install over the top normally.

App crashes or won't start on a TCL or budget Android TV?

Three TV-side settings cause most crashes of sideloaded apps on TCL sets:

1. Android System WebView disabled or outdated — the player runs inside WebView. TV Settings → Apps → See all apps → show system apps → Android System WebView → Enable, then update it in the Play Store. Check its state over ADB with adb shell dumpsys webviewupdate.

2. TCL "Safe Guard" watchdog — open the pre-installed Safe Guard app → Automatic start setting → disable automatic management, or allow Signage TV Player. Safe Guard silently kills or blocks sideloaded apps otherwise.

3. Google Play Protect — Play Store → profile icon → Play Protect → Settings → turn off scanning, or approve the app when prompted. Play Protect can kill or even uninstall sideloaded APKs on Google TV.

Still crashing? From v1.5.4 the app shows the crash reason on screen the next time it opens. You can also capture it with adb logcat -b crash -d after reproducing the crash.

TV can't find or reach the PC?

Update both apps first. Versions before v1.5.5 advertised the wrong address when the PC had a VPN or virtual network adapter (Tailscale, Hyper-V, VPN clients). The desktop app now ignores those, and its Settings page shows the exact URL to type on the TV.

Same network: the TV and PC must be on the same router network. A phone hotspot, guest Wi-Fi, or a router with AP/client isolation switched on blocks device-to-device traffic — turn isolation off, or put both on the main network.

Windows Firewall: when Windows asks whether "Signage Manager" may access the network, choose Allow and tick "Private networks". If it was blocked already: Windows Security → Firewall → Allow an app through firewall → enable Signage Manager for Private networks.

From v1.5.5 the TV app tests the connection when you press Connect and tells you what failed — refused means firewall or the app isn't running; timeout means the wrong network or AP isolation.

STEP 01

Reveal Developer Mode

On the TV go to Settings → Support → TV Information, then click the TV logo 5 times to reveal the Developer Mode app in the LG Content Store.

STEP 02

Install the Developer Mode app

Open LG Developer Mode from the Content Store, sign in with a free LG developer account, and turn Dev Mode Status on.

STEP 03

Install webOS Dev Manager

On the Windows PC, download webOS TV Dev Manager from the LG Developer site, or install the VS Code extension. Add the TV's IP address as a device.

STEP 04

Install the IPK

In webOS Dev Manager, select the TV, click Install App, and choose the downloaded signage-webos-player.ipk.

STEP 05

Set the server URL

Launch Signage Player from the LG home screen, enter the server URL shown on the desktop app's Settings page, and press Connect.

STEP 06

Done — it reconnects on its own

The player auto-connects on the next launch. Press Back on the remote to return to settings and change the server URL.

Prefer the command line?

Install LG's @webosose/ares-cli and run:

ares-install --device <TV-name> signage-webos-player.ipk
STEP 01

Enable Developer Mode

On the TV open Apps, then quickly type 12345 on the remote. A Developer Mode dialog appears — switch it ON and enter your PC's IP address.

STEP 02

Restart the TV

The TV prompts you to restart. After the reboot a DEVELOP MODE banner appears at the top of the Apps screen, confirming it took.

STEP 03

Install Tizen Studio

Download Tizen Studio from the Samsung developer site and install it on the Windows PC. Open Device Manager from the toolbar.

STEP 04

Connect the TV

In Device Manager, click Remote Device Manager → Scan, or add the TV's IP manually. Right-click the TV and choose Connect — the status should turn green.

STEP 05

Install the WGT

Go to Tools → Tizen → Install Tizen App, pick the connected TV, and choose the downloaded signage-tizen.wgt.

STEP 06

Set the server URL

Launch Signage Player from Smart Hub, enter the server URL from the desktop app's Settings page, and press Connect. It reconnects by itself next time.

Prefer the command line?

With the Tizen CLI on your PATH, connect the TV over SDB and run:

tizen sdb connect <TV-IP> && tizen install -n signage-tizen.wgt -t <device-id>

Patch log

What changed.

Full details for every release live on GitHub Releases.

v1.9.1Latest
  • Fixed: Check for Updates could tell you that you were up to date when the check had in fact failed. A rate limit, an unreachable release list and no internet at all all produced the same green tick, so a computer could sit on an old version for months believing it was current. It now says which happened, and why
  • Fixed: the check could sit on Checking for updates… indefinitely when the network answered and then went quiet. It now gives up after twenty seconds and tells you
  • Fixed: choosing Update Now from the Help menu downloaded the update with nothing on screen to show for it, and then closed the app. The progress bar, and anything that goes wrong, now appear in the bar across the top
  • Fixed: an update that arrived incomplete, or an installer that would not start, could close the app without installing anything. Downloads are now checked against the release’s own checksum before they are run, and the app only closes once the installer has actually started
  • The update bar now says what is in a release before you commit to restarting for it
v1.9.0
  • New app: Social Mix — Instagram, Facebook and X on one wall, every post badged with the network it came from so a room can tell them apart at a glance. Each network is read from a link, either a wall service's feed or an RSS feed
  • New app: MustHaveMenus — put a menu you designed at musthavemenus.com on a screen by pasting its Share link, and republish the design to update the screens. A menu with several pages can play through all of them. A link that was never published is refused when you save it, instead of leaving a blank screen in the dining room
  • New: a Four columns preset in the app zone editor — four full-height panes side by side, the upright counterpart to Quarters
  • Social walls now draw posts that are only words. A post with no picture used to leave a photo-shaped gap on the wall
v1.8.3
  • New: after you install an update, the app now shows what changed the first time it starts — naming the version you came from, listing the changes, and appearing only once. Previously an update arrived with nothing to say for itself
  • The update prompt is back to its plain wording. It had started appending a change count as soon as release notes began being published, which made updating look different when nothing about it had changed
  • Fixed: release notes are shown as plain sentences, instead of leaving formatting marks like **bold** visible in the text
v1.8.2
  • Reporting a problem no longer sends you to GitHub. Fill in the form, press Send report, and it reaches us directly — no GitHub account, no second step in a browser
  • You can leave your email with a report, so we can actually reply. It is optional and used for nothing else
  • The app tells you honestly what happened: whether the report was filed straight away, or received and held because our end was unreachable. If we cannot be reached at all it falls back to the old browser flow, so a report is never lost
v1.8.1
  • New: six ready-made emergency and flash messages — a fire drill, a full-building evacuation and a lockdown, plus a full car park, an early close and overnight maintenance — so the Emergency page is useful the first time you open it. Edit them to suit your building; any you delete stay deleted
  • The Emergency page now opens with the four figures you actually want in an incident: what is live, what is prepared, how many screens the broadest message reaches, and how many screens are offline and will pick it up when they reconnect
  • Emergency and Flash messages are now listed separately, emergencies first, so the most serious message is never sitting below a parking notice. Anything you create afterwards files itself into the right section on its own
  • Fixed: a rare fault in the progress bar could leave a screen stuck on whatever it was showing instead of moving to the next item. The next item is now scheduled before the bar is drawn, so nothing the bar does can strand the rotation
  • Fixed: dashes and the × symbol appeared as garbled characters throughout the Screen Layouts page
v1.8.0
  • New: apps — 21 boards that fill themselves from a live source instead of a file you upload: Instagram and Facebook walls, a follower counter for each, YouTube (videos, Shorts, live streams and playlists), Weather (three styles, seven days, no API key needed), Google Calendar, Google Slides, Google Drive, OneDrive, SharePoint, Power BI, Canva, Live TV with adverts, Split Screen, Simple Clock, World Clock, QR Code, Motivational Quotes, and Countdown / Count-up
  • New: Designer — build a board from scratch with a proper shape library, live widgets, typed QR codes and effects, then keep what you make in a team template library with filters to find it again
  • New: screen layouts — divide a screen into zones, each one playing anything the manager can serve, so a single TV can show a video, a menu and a ticker at once
  • New: emergency and flash messages — put an urgent notice on one screen or on every screen at once. Screens leave their playlist immediately and pick it up again the moment the message is cleared
  • Templates are now sorted into categories, with extra packs downloaded only when you want them rather than shipped with the app
  • Fixed: the zone editor crashed when it was opened; an emergency message could be unreadable for two separate reasons; the weather data provider is now credited as its licence requires; and a hard review of Motivational Quotes turned up six defects, one of them serious
v1.7.0
  • New: templates — six ready-made layouts (Fullscreen, Fullscreen + Ticker, Lower Third, Branded Frame, Welcome / Lobby and Portrait Poster) with your own colours, font, logo and clock, previewed live in the app before you assign them
  • A template can be set for one screen, for a whole group, or as the default for everything; each screen renders its own, and remembers it so it still looks right if it powers on while the manager is off
  • New: screen pairing — a TV shows an 8-letter code and you add it from the Devices page, so screens are claimed on purpose instead of any device on the network connecting itself. Existing screens keep working exactly as before; pairing only becomes mandatory if you switch it on in Settings
  • Managing the server is now limited to this PC. TVs still connect normally, but another machine on the network can no longer list your screens or push content to them
  • Fixed a serious bug on LG webOS 4 TVs: any scheduled content caused a permanently black screen. Those panels also had the "no content" screen and the new layouts rendered incorrectly — all corrected
  • Un-pair or remove a screen and it now returns to a pairing code immediately, instead of leaving old content on the wall
