How to install on LG webOS

01

Enable Developer Mode

On your LG TV go to Settings → Support → TV Information, then click the TV logo 5 times to reveal the Developer Mode app in the LG Content Store.

02

Install Developer Mode app

Open the LG Developer Mode app from the Content Store, sign in with an LG developer account (free), and turn Dev Mode Status on.

03

Install webOS Dev Manager

On your Windows PC, download webOS TV Dev Manager from the LG Developer site or install the VS Code extension. Add your TV's IP address as a device.

04

Install the IPK

In webOS Dev Manager, select your TV, click Install App, and choose the downloaded signage-webos-player.ipk file.

05

Configure server URL

Launch Signage Player from the LG Home Screen. Enter the server URL shown in the desktop app's Settings page and press Connect.

06

Done — reconnects automatically

The player auto-connects on next launch. Press the Back button on your remote to return to settings and change the server URL.

Command-line install (ares-cli)

If you prefer the terminal, install LG's @webosose/ares-cli and run:

ares-install --device <TV-name> signage-webos-player.ipk
// INSTALL SEQUENCE — SAMSUNG TIZEN

How to install on Samsung Tizen

01

Enable Developer Mode

On your Samsung TV go to Apps, then quickly enter 12345 on the remote. A Developer Mode dialog will appear — toggle it ON and enter your PC's IP address.

02

Restart the TV

The TV will prompt you to restart. After reboot, a DEVELOP MODE banner should appear at the top of the Apps screen, confirming developer mode is active.

03

Install Tizen Studio

Download Tizen Studio from the Samsung developer site and install it on your Windows PC. Open Device Manager from the toolbar.

04

Connect the TV

In Device Manager, click Remote Device Manager → Scan or add the TV IP manually. Right-click the TV and select Connect. The status should turn green.

05

Install the WGT

In Tizen Studio, go to Tools → Tizen → Install Tizen App, select the connected TV, and choose the downloaded signage-tizen.wgt file. Or run:

tizen install -n signage-tizen.wgt -t <device-id>
06

Configure & enjoy

Launch Signage Player from the Samsung Smart Hub. Enter the server URL from the desktop app's Settings page and press Connect. The app auto-reconnects on next launch.

CLI install (Tizen CLI)

If you have the Tizen CLI on your PATH, connect the TV via SDB and run:

tizen sdb connect <TV-IP> && tizen install -n signage-tizen.wgt -t <device-id>

App crashes or won't start on a TCL / cheaper Android TV?

Three TV-side settings cause most crashes of sideloaded apps on TCL sets:

1. Android System WebView disabled/outdated — the player runs in WebView. TV Settings → Apps → See all apps → show system apps → Android System WebView → Enable, then update it in the Play Store. Check its state over ADB with adb shell dumpsys webviewupdate.

2. TCL "Safe Guard" app watchdog — open the pre-installed Safe Guard app → Automatic start setting → disable automatic management (or allow Signage TV Player). Safe Guard silently kills or blocks sideloaded apps otherwise.

3. Google Play Protect — Play Store → profile icon → Play Protect → Settings → turn off scanning (or approve the app when prompted). Play Protect can kill or even uninstall sideloaded APKs on Google TV.

Still crashing? From v1.5.4 the app shows the crash reason on screen the next time it opens. You can also capture it with adb logcat -b crash -d after reproducing the crash.

TV can't find or reach the PC?

Update both apps to v1.5.5 first. Older versions advertised the wrong address when the PC had a VPN or virtual network adapter (Tailscale, Hyper-V, VPN clients…) — the desktop app now ignores those and the Settings page shows the exact URL to enter on the TV.

Same network: the TV and PC must be on the same router network. A phone hotspot, guest Wi-Fi, or a router with AP/client isolation enabled blocks device-to-device traffic — disable isolation in the router settings or use the main (non-guest) network for both.

Windows Firewall: when Windows asks whether "Signage Manager" may access the network, choose Allow (tick "Private networks"). If it was blocked: Windows Security → Firewall → Allow an app through firewall → enable Signage Manager for Private networks.

From v1.5.5 the TV app tests the connection when you press Connect and tells you exactly what failed (refused = firewall/app not running; timeout = wrong network or AP isolation).

Skip the setup screen via ADB

Replace 192.168.1.x with the IP shown in the desktop app's Settings page, then run this once after installing the APK:

adb shell am start -n com.signage.tvplayer/.SetupActivity --es SERVER_URL "http://192.168.1.x:3001"

Changelog

What's new in each release — see GitHub Releases for full details.

v1.6.0 Latest
  • New: device groups — organise screens by location or purpose (Lobby, Cafeteria, Menu Boards) and push content or a whole project to every screen in a group at once
  • A screen can belong to several groups, each with its own colour; the Devices page shows group tags on every TV and lets you filter by group or show only ungrouped screens
  • Group pushes report exactly what happened — how many screens received the content and how many were skipped because they were offline
  • Fixed: a TV that reconnected could silently fall out of its groups, and renaming a device no longer risks clearing other fields
v1.5.5
  • Fixed auto-discovery and manual connection failing when the PC has a VPN or virtual network adapter (Tailscale, Hyper-V, WSL…) — the server now advertises the real LAN address on every network it is connected to
  • Settings page now shows the actual URL to enter on the TV (it previously showed "localhost", which only works on the PC itself)
  • Android TV: discovery now holds a Wi-Fi multicast lock — wireless TVs previously never received the beacon at all
  • Android TV: pressing Connect now tests the connection and explains exactly what failed (firewall, wrong network, AP isolation…)
  • Android TV: the player shows a clear "can't reach the server" banner with instructions instead of a silent black screen
  • New: anonymous usage statistics, with an opt-out under Settings → Privacy — only app version, OS and named feature events are shared, never your content or media
v1.5.4
  • Fixed Android TV app crashing on TCL and other low-memory TVs — a WebView renderer crash (heavy video / out-of-memory) now rebuilds the player instead of killing the app
  • Removed the emoji startup component that could crash the app at launch on TVs without Google font services
  • If the app ever crashes, it now shows the exact crash reason on screen at next launch
  • Player page now works on older TV browsers (Chromium < 87) — content layers no longer collapse to a black screen
  • Player now skips unplayable videos/images (unsupported codec) instead of hanging on a black screen
  • Website: added a TCL troubleshooting section (WebView, Safe Guard, Play Protect)
